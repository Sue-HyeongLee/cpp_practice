 * 1단계
 c++보다 c언어로 구성된 bank program 만들기. (헤더, 소스코드 잘 분리해서)

 둘 이상의 고객 정보 저장을 위해서 배열을 사용한다.
 계좌번호는 정수의 형태이다.
